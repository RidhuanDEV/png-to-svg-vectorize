# PNG to SVG Vectorize 1.5.0

Center lines for plotters and lasers, editing in the app, and automation for batches.

## What's new

- **Center lines.** Line drawings, sketches and handwriting become one clean stroke along the middle of each line —
  ready for plotters, laser engraving and embroidery (also as DXF).
- **Edit shapes.** Click a shape to recolor it, give it the color of another shape, or delete it — with undo and redo.
- **Layers per color** so Figma, Illustrator and Inkscape show one layer per color.
- **Watch folder** (desktop): pictures copied into a folder are converted automatically into another folder. Also on
  the command line: `png2svg watch`.
- **Batch report** as CSV or JSON, with the similarity of every result.
- **Keyboard shortcuts** — press `?` to see them all.

## Install

Same as 1.0.0: see the [user guide](../user-guide.en.md#1-install). Builds are not code-signed.

# PNG to SVG Vectorize 1.5.0 (Bahasa Indonesia)

- **Garis tengah.** Gambar garis, sketsa, dan tulisan tangan menjadi satu goresan rapi di tengah setiap garis — siap
  untuk plotter, ukir laser, dan bordir (juga sebagai DXF).
- **Sunting bentuk.** Klik sebuah bentuk untuk mengubah warnanya, memakai warna bentuk lain, atau menghapusnya — dengan
  urungkan dan ulangi.
- **Lapisan per warna** sehingga Figma, Illustrator, dan Inkscape menampilkan satu lapisan per warna.
- **Folder pantau** (desktop): gambar yang disalin ke sebuah folder otomatis diubah ke folder lain. Juga di baris
  perintah: `png2svg watch`.
- **Laporan batch** CSV atau JSON, lengkap dengan kemiripan setiap hasil.
- **Pintasan keyboard** — tekan `?` untuk melihat semuanya.

Instalasi: lihat [panduan](../user-guide.id.md#1-instalasi).
