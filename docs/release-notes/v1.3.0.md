# PNG to SVG Vectorize 1.3.0

Smoother results from small, blurry and JPEG pictures — with an optional AI step that runs on your own computer.

## What's new

- **Enhance with AI (optional).** An AI model cleans and enlarges the picture before it is turned into vectors, so
  edges come out smoother. On damaged web pictures the similarity to the clean original rises by about half a point
  (median), with files only slightly larger.
- **Automatic by default**: AI is used only where it helps — pictures smaller than 1000 px or JPEGs. Choose *Off* or
  *Always* in the style panel.
- **Download once, offline afterwards.** Models are not in the installer: download one in Settings → Processing
  (*Illustrations* 17 MB, *General* 5 MB). It comes from this project's GitHub release, is verified, and stays on your
  computer.
- **Uses your graphics card** when supported (any GPU on Windows via DirectML, Apple Silicon via Core ML), otherwise
  the processor. Not available on Intel Macs.

## Install

Same as 1.0.0: see the [user guide](../user-guide.en.md#1-install). Builds are not code-signed.

# PNG to SVG Vectorize 1.3.0 (Bahasa Indonesia)

- **Perhalus dengan AI (opsional).** Model AI membersihkan dan memperbesar gambar sebelum diubah menjadi vektor
  sehingga tepinya lebih halus. Pada gambar web yang rusak, kemiripan dengan aslinya naik sekitar setengah poin
  (median) dengan ukuran berkas hanya sedikit lebih besar.
- **Otomatis secara bawaan**: AI hanya dipakai saat membantu — gambar di bawah 1000 px atau JPEG. Pilih *Mati* atau
  *Selalu* di panel gaya.
- **Unduh sekali, setelah itu offline.** Model tidak ada di installer: unduh di Pengaturan → Pemrosesan (*Ilustrasi*
  17 MB, *Umum* 5 MB). Berkas diambil dari rilis GitHub proyek ini, diverifikasi, dan disimpan di komputer Anda.
- **Memakai kartu grafis** bila didukung (GPU apa pun di Windows lewat DirectML, Apple Silicon lewat Core ML), selain
  itu prosesor. Tidak tersedia di Mac Intel.

Instalasi: lihat [panduan](../user-guide.id.md#1-instalasi).
