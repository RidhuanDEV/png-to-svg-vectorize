# PNG to SVG Vectorize 1.6.0

Logos and icons come out the way a designer would draw them: one clean path per shape, straight edges, sharp
corners, no background — often in under a kilobyte.

## What's new

- **New Logo / icon engine.** Straight sides become real lines (snapped to horizontal/vertical, parallel sides
  aligned), corners stay sharp, every shape is its own path with a stable id (ready to animate), neighbours share
  their edges (no gaps, no stroke tricks), the background is left out and the SVG is trimmed to the artwork. Our own
  logo: 4 paths in 468 bytes instead of 7 paths in 19.7 KB.
- **Corner rounding** when you want it: round every corner by the same radius.
- **Pixel art** style: edges follow the pixel grid exactly.
- A note appears when a picture is not flat artwork (photos, shading) — the Cartoon or Flat illustration style keeps
  more detail there.
- The Python package now needs Python 3.11 or newer (security fixes in Pillow 13).

## Install

Same as 1.0.0: see the [user guide](../user-guide.en.md#1-install). Builds are not code-signed; every download has a
SHA-256 checksum in `SHA256SUMS.txt`.

# PNG to SVG Vectorize 1.6.0 (Bahasa Indonesia)

- **Mesin Logo / ikon baru.** Sisi lurus menjadi garis sungguhan (di-snap horizontal/vertikal, sisi sejajar
  disamakan), sudut tetap tajam, setiap bentuk menjadi path tersendiri dengan id tetap (siap dianimasikan), bentuk
  yang bersebelahan berbagi tepi (tanpa celah, tanpa trik stroke), latar tidak disertakan, dan SVG dipotong ke batas
  gambar. Logo kami sendiri: 4 path dalam 468 byte, bukan 7 path dalam 19,7 KB.
- **Pembulatan sudut** bila diinginkan: semua sudut dibulatkan dengan radius yang sama.
- Gaya **Pixel art**: tepi mengikuti grid piksel persis.
- Muncul catatan bila gambar bukan karya datar (foto, bayangan) — gaya Kartun atau Ilustrasi datar menyimpan lebih
  banyak detail.
- Paket Python kini butuh Python 3.11 atau lebih baru (perbaikan keamanan di Pillow 13).
