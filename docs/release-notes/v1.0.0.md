First release of **PNG to SVG Vectorize** as a desktop app for Windows and macOS: turn raster illustrations
(PNG, WebP, JPEG) into clean, editable SVG with gradient fills and crisp outlines — entirely on your computer.

## Downloads

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `PNG-to-SVG-Vectorize-Setup-1.0.0.exe` (installer, no admin rights) or `…-windows-x64-portable.zip` |
| macOS 12+ Apple Silicon | `PNG-to-SVG-Vectorize-1.0.0-arm64.dmg` |
| macOS 12+ Intel | `PNG-to-SVG-Vectorize-1.0.0-x64.dmg` |

The app is free and open source and **not code-signed**. Windows SmartScreen: *More info → Run anyway*. macOS:
System Settings → Privacy & Security → *Open Anyway* (details and the `xattr` fix in the
[user guide](https://github.com/RidhuanDEV/png-to-svg-vectorize/blob/main/docs/user-guide.en.md#1-install)).
Windows needs the WebView2 Runtime (built into Windows 11 and almost every Windows 10).

## Highlights

- Drag and drop, queue with progress, side-by-side and slider comparison with synchronized zoom up to 800 %,
  fills-only / outlines-only views, similarity score.
- Presets for cartoons, flat illustrations, logos/icons and photo → poster; advanced settings with re-processing.
- Save one SVG, save all to a folder (never overwrites), copy SVG code. English and Bahasa Indonesia, light/dark.
- Pure-path SVG output with linear and elliptical radial gradients and unique ids per file.
- Quality: median similarity 99.72 % on a 27-image license-free comparison set, 98.65 % on detailed
  image-generator illustrations; files 63 % smaller than v0.1. Numbers in
  [docs/bench.md](https://github.com/RidhuanDEV/png-to-svg-vectorize/blob/main/docs/bench.md).
- Private: a local service on 127.0.0.1 with a per-session key; no uploads, no telemetry.

## Known limitations

- Very glossy, strongly non-linear shading can show a few soft bands; very faint tiny color spots may merge into
  their surroundings; hairlines under ~1.5 px that are mostly anti-aliasing can be lost.
- Photos are converted to a poster-like look, not photo-realistic vectors.
