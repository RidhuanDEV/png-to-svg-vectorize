# PNG to SVG Vectorize 1.4.0

Studio options: control the colors, drop the background, and save to the format your next tool needs.

## What's new

- **Choose the colors.** Limit a result to 2–32 flat colors, or lock its palette and change, add or remove colors.
  Grayscale and black & white (with a threshold) for stamps, signatures and logos.
- **Transparent background** and **cut-out shapes** (nothing overlaps — ready for cutting machines).
- **PDF, EPS, DXF and PNG** next to SVG: vector PDF with real gradients, EPS for print shops, DXF for CAD and laser,
  PNG drawn from the vector at up to 8×.
- **Paste** a copied picture with Ctrl+V; **Copy PNG**.
- **Style profiles**: save a style under a name, share it as a file, and use the same file on the command line.

## Install

Same as 1.0.0: see the [user guide](../user-guide.en.md#1-install). Builds are not code-signed.

# PNG to SVG Vectorize 1.4.0 (Bahasa Indonesia)

- **Atur warnanya.** Batasi hasil menjadi 2–32 warna datar, atau kunci paletnya lalu ubah, tambah, atau hapus warna.
